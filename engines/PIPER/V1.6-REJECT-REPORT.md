# Piper Hindi v1.6 (IndicF5 patch) — Test aur Reject Report

Test date: 19 Nov 2026 · Package: `Piper_Hindi_Neural_Voice_v1.6_INCREMENTAL_PATCH.zip`

## 1. Jo pass hua
- Patch ke apne **13/13 tests pass** (mock neural render ke saath).
- Patch lagane ke baad poore engine ke **81/81 tests pass** — purana Piper kuch nahi toota.
- Adapter ka design theek hai: exact transcript check, sirf profile wale pronunciation overrides + audit, sentence chunking, model cache, saaf error messages.

## 2. Jo REJECT hua (aur kyun)

### R1 — Asli awaaz ka test hi nahi hua (sabse bada)
Patch ka apna report kehta hai: `real_model_loaded: false`, `real_audio_quality_verified: false`.
Yahan bhi nahi ho paya:
- `https://huggingface.co/ai4bharat/IndicF5/resolve/main/config.json` → **HTTP 401** (model gated; terms accept + token chahiye)
- `torch` installed nahi, aur machine par sirf **2 GB RAM** (model 0.4B = ~1.6 GB weights + runtime) → OOM
**Verdict:** naturalness ka dawa abhi **sabit nahi**. 8 GB+ RAM aur HF access ke bina test nahi hoga.

### R2 — Patch ka koi CLI/route nahi tha (dead code)
README khud kehta hai "apne app ke explicit route se bulayein" — yani `app.py` se use hi nahi hota tha.
**Fix:** `python app.py indicf5-render "<text>" --character आरव --emotion pain --out out.wav` juda.

### R3 — Kirdaar ke naam match hi nahi karte the
Profile me naam Latin hain (`narrator`, `arav`), engine Devanagari me kaam karta hai (`वाचक`, `आरव`, `माँ`, `दादी`).
Isliye seedha reject: `unknown character 'दादी'`.
**Fix:** alias map — वाचक→narrator, आरव→arav, माँ→mother, दादी→grandmother, भूत→ghost…

### R4 — Har render reference audio ke bina reject
`reference audio not found for arav/neutral` — yani har kirdaar × har bhaav ka **apna 2+ second ka recording + exact transcript** chahiye.
25 kirdaar × 4 bhaav = **100 recordings**. Ye patch khud nahi de sakta (aur nahi dena chahiye — consent wali baat hai).

### R5 — Doc aur code ka path alag
README: sample `references/` me rakho. Code: profile file ke saath wala folder, yani `profiles/references/`.
**Fix:** dono jagah ek hi baat likhi, aur `profiles/references/` bana diya.

### R6 — Lamba bina-space text toda nahi jata tha
400 akshar ka ek token `max_chars=100` ke bawajood **400 ka hi chunk** banta tha → model ke context se bahar.
**Fix:** ab hard split — `[100, 100, 100, 100]`.

### R7 — Default profile file maujood hi nahi thi
README kehta hai copy karke `profiles/indicf5_characters.json` banao, par zip me sirf `.example.json` hai →
`voice profile file not found`. **Fix:** copy kar di + CLI ka default usi naam par.

### R8 — Zip me `__pycache__/*.pyc` (cpython-313) bhi hai
Kaam kharab nahi karta, par patch me compiled cache nahi hona chahiye.
