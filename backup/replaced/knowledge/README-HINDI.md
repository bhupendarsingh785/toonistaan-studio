# Local Brain — poori seekh ek jagah

- `local-brain.json` — machine ke liye (engines isse padhein)
- `local-brain.html` — insaan ke liye (phone par khulta hai, search ke saath)

**Kya hai isme:** sur ke target, robot lagne ke 5 karan, smoothness ke niyam, bhaav ke signal,
shabd galat (piper G2P), 8 beat pattern, blueprint (kahani/vlog/horror/gaana), QA checklist, aur meri galtiyan.

**Engines:** `python tools/engine_sync.py` chalao → `voice/engines/<engine>/` me
`config.json` + `README-hindi.md` ban jayega (edge, espeak, piper, elevenlabs).
